# Game_Practice

Practicing making a web game with AI

## 🐍 SNAKE

바닐라 HTML / CSS / JavaScript로 만든 스네이크 게임. 외부 라이브러리도, 음원 파일도 없습니다.

### 실행

저장소를 받은 뒤 로컬 서버로 띄웁니다. (`file://`로 직접 열어도 동작하지만 서버 쪽이 안전합니다.)

```bash
python -m http.server 8123
```

브라우저에서 `http://localhost:8123` 접속.

### 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 뱀 이동 (한글 자판 상태에서도 `ㅈㅁㄴㅇ`로 동작) |
| `ESC` | 일시정지 / 재개 |
| `M` | 배경음악 켜기 / 끄기 |
| `Space` / `Enter` | 화면 넘기기 (시작 · 메인으로) |

진행 방향의 정반대 입력은 즉사를 막기 위해 무시합니다. 한 틱에 최대 2개까지 입력을 큐에 담아 빠른 연속 조작을 받아냅니다.

조작법은 시작 화면에도 표시됩니다.

### 화면 구성

게임 화면 위에는 아무 UI도 얹지 않았습니다. 캔버스 **바깥 상단 바**에 다음이 놓입니다.

| 위치 | 내용 |
|---|---|
| 왼쪽 | `HI-SCORE` — 역대 최고 길이 (localStorage에 저장) |
| 가운데 | `승리까지` — 승리(355)까지 남은 칸 수. 시작 시 **350** |
| 오른쪽 | `BGM` — 배경음악 토글 |

### 규칙

- 그리드 **32 × 18** (576칸), 뱀은 중앙에서 길이 **5**로 시작
- 먹이(작은 쥐)는 뱀의 머리·몸통이 없는 칸 중에서만 무작위로 생성
- 쥐를 먹을 때마다 몸통이 한 칸 길어짐
- **승리** — 길이 **355** 달성 시 `You Win!`
- **패배** — 그리드를 벗어나거나 자기 몸통 칸으로 진입하면 `Better Luck Next Time`

### 속도 곡선

**1.4칸/초**에서 시작해, 쥐 하나를 먹을 때마다 **정확히 +0.04743칸/초**씩 균일하게 빨라집니다. 승리 길이인 355칸에서 최고 속도 **18칸/초**에 도달합니다.

```
speed(len)    = 1.4 + (18 - 1.4) × (len - 5) / 350     // 칸/초
interval(len) = 1000 / speed(len)                       // ms
```

| 길이 | 체감 속도 | 틱 간격 |
|---:|---:|---:|
| 5 | 1.40칸/초 | 714ms |
| 55 | 3.77칸/초 | 265ms |
| 105 | 6.14칸/초 | 163ms |
| 155 | 8.51칸/초 | 117ms |
| 205 | 10.89칸/초 | 92ms |
| 255 | 13.26칸/초 | 75ms |
| 305 | 15.63칸/초 | 64ms |
| 355 | 18.00칸/초 | 56ms |

속도 증가폭이 균일하므로 체감 난이도는 앞구간에서 빠르게 오르고 뒤로 갈수록 완만해집니다. 반대로 후반에 몰아치는 곡선을 원하면 `game.js`의 `speedFor()`를 간격 선형(`interval = 1000 - (len-5) × k`)으로 바꾸면 됩니다.

### 사운드

음원 파일 없이 **Web Audio API로 실시간 합성**하는 8비트 칩튠입니다. 펄스파(리드/하모니) + 삼각파(베이스) + 노이즈(퍼커션) 구성으로, 수록곡(타이틀 · 게임플레이 · 승리 · 패배 징글)은 모두 오리지널 창작곡입니다.

게임플레이 곡은 **뱀 속도에 맞춰 템포가 올라갑니다** (96 → 186 BPM). 일시정지하면 재생 위치를 유지한 채 멈췄다가 재개됩니다. 브라우저 자동재생 정책상 첫 클릭이나 키 입력 전까지는 소리가 나지 않습니다.

### 디버그

게임 진행 중에만 동작하는 단축키:

| 키 | 동작 |
|---|---|
| `` ` `` | 길이 +50 |
| `Shift` + `W` | 즉시 승리 화면 |
| `Shift` + `L` | 즉시 패배 화면 |

브라우저 콘솔에서 속도 곡선을 확인할 수 있습니다:

```js
SNAKE.state()    // 현재 상태 · 길이 · 틱 간격 · 체감 속도 · 남은 칸
SNAKE.curve(50)  // 길이 50칸 간격으로 속도 곡선 전체 출력
```

### 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 상단 바 · 캔버스 · 버튼 오버레이 마크업 |
| `style.css` | 레트로 네온 테마, 16:9 반응형 레이아웃 |
| `game.js` | 상태 머신, 게임 로직, 캔버스 렌더링, SNAKE 로고, 쥐 아이콘 |
| `audio.js` | 칩튠 사운드 엔진과 수록곡 |
