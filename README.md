# Game_Practice

Practicing making a web game with AI

## 🐍 SNAKE

바닐라 HTML / CSS / JavaScript로 만든 스네이크 게임. 외부 라이브러리도, 음원 파일도 없습니다.

### 실행

저장소를 받은 뒤 로컬 서버로 띄웁니다. (`file://`로 직접 열어도 동작하지만 서버 쪽이 안전합니다.)

```bash
python -m http.server 8123
```

브라우저에서 `http://localhost:8123` 접속.

### 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 뱀 이동 (한글 자판 상태에서도 `ㅈㅁㄴㅇ`로 동작) |
| `Space` / `Enter` | 화면 넘기기 (시작 · 메인으로) |
| `M` | 배경음악 음소거 토글 |

진행 방향의 정반대 입력은 즉사를 막기 위해 무시합니다. 한 틱에 최대 2개까지 입력을 큐에 담아 빠른 연속 조작을 받아냅니다.

### 규칙

- 그리드 **32 × 18** (576칸), 뱀은 중앙에서 길이 **5**로 시작
- 먹이는 뱀의 머리·몸통이 없는 칸 중에서만 무작위로 생성
- 먹이를 먹을 때마다 몸통이 한 칸 길어짐
- **승리** — 길이 **300** 달성 시 `You Win!`
- **패배** — 그리드를 벗어나거나 자기 몸통 칸으로 진입하면 `Better Luck Next Time`

### 속도 곡선

먹을 때마다 틱 간격이 **3.2ms**씩 줄어듭니다 (하한 55ms).

```
interval(len) = max(55, 1000 - (len - 5) × 3.2)   // 단위: ms
```

간격이 일정하게 줄어도 체감 속도(칸/초)는 뒤로 갈수록 급격히 치솟습니다.

| 길이 | 틱 간격 | 체감 속도 |
|---:|---:|---:|
| 5 | 1000ms | 1.0칸/초 |
| 100 | 696ms | 1.4칸/초 |
| 200 | 376ms | 2.7칸/초 |
| 250 | 216ms | 4.6칸/초 |
| 280 | 119ms | 8.4칸/초 |
| 300 | 56ms | 17.9칸/초 |

앞의 200칸에서 속도가 2.7배 오르는 동안, 마지막 100칸에서 7배가 더 오릅니다.

### 사운드

음원 파일 없이 **Web Audio API로 실시간 합성**하는 8비트 칩튠입니다. 펄스파(리드/하모니) + 삼각파(베이스) + 노이즈(퍼커션) 구성으로, 수록곡(타이틀 · 게임플레이 · 승리 · 패배 징글)은 모두 오리지널 창작곡입니다.

게임플레이 곡은 **뱀 속도에 맞춰 템포가 올라갑니다** (96 → 186 BPM). 브라우저 자동재생 정책상 첫 클릭이나 키 입력 전까지는 소리가 나지 않습니다.

### 디버그 단축키

게임 진행 중에만 동작합니다.

| 키 | 동작 |
|---|---|
| `` ` `` | 길이 +50 |
| `Shift` + `W` | 즉시 승리 화면 |
| `Shift` + `L` | 즉시 패배 화면 |

### 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 캔버스 · 버튼 오버레이 마크업 |
| `style.css` | 레트로 네온 테마, 16:9 반응형 레이아웃 |
| `game.js` | 상태 머신, 게임 로직, 캔버스 렌더링, SNAKE 로고 |
| `audio.js` | 칩튠 사운드 엔진과 수록곡 |
