# Game_Practice

Practicing making a web game with AI

## 🐍 SNAKE

> **v0.5.1** — 변경 이력은 문서 맨 아래 [변경 이력](#변경-이력) 참고

바닐라 HTML / CSS / JavaScript로 만든 스네이크 게임. 외부 라이브러리도, 이미지도, 음원 파일도 없습니다. 뱀·쥐·바닥·로고·음악까지 전부 코드로 그리고 만듭니다.

### 플레이

**https://wilstein91.github.io/Game_Practice**

### 로컬에서 실행

```bash
python -m http.server 8123
```

브라우저에서 `http://localhost:8123` 접속.

### 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 뱀 이동 (한글 자판 상태에서도 `ㅈㅁㄴㅇ`로 동작) |
| `ESC` | 일시정지 / 재개 (상점이 열려 있으면 닫기) |
| `M` (또는 상단 바 `BGM` 클릭) | 배경음악 음량 **Mute → 1 → 2 → 3** 순환 |
| `Space` / `Enter` | 화면 넘기기 (시작 · 메인으로) |

터치 기기와 좁은 화면(≤ 860px)에서는 캔버스 아래에 **십자 조작부**가 나타납니다.

| 조작 | 동작 |
|---|---|
| 방향 버튼 `▲` `◀` `▼` `▶` | 뱀 이동. 방향 입력이 통하지 않는 상태에서는 흐려지고 눌리지 않는다 |
| 가운데 버튼 | 상태에 따라 **시작 `▶` / 일시정지 `❚❚` / 계속하기 `▶` / 처음으로 `↺`** 로 바뀐다 |
| 캔버스 스와이프 | 24px 이상 밀면 그 방향으로 이동. 대각선은 더 많이 움직인 축만 읽는다 |

버튼은 한 변 **64px 이상**(좁은 화면 54px)을 유지하고, `click` 대신 `pointerdown`으로 받습니다. 모바일 브라우저의 `click`은 300ms 가까이 늦게 오는 경우가 있어 빠른 구간에서 한 칸씩 밀리기 때문입니다.

진행 방향의 정반대 입력은 즉사를 막기 위해 무시합니다. 한 틱에 최대 2개까지 입력을 큐에 담아 빠른 연속 조작을 받아냅니다. 조작법은 시작 화면에도 표시됩니다.

### 화면 구성

게임 화면 위에는 아무 UI도 얹지 않았습니다. 캔버스 **바깥 상단 바**에 다음이 놓입니다.

| 위치 | 내용 |
|---|---|
| **상태 배지** | 현재 상태를 **점 색깔과 문구로 함께** 표시 (아래 표) |
| `HI-SCORE` | 역대 최고 점수 |
| `🐭 Mice` | 보유 재화 (먹은 쥐 수) |
| `승리까지` | 승리(400)까지 남은 칸 수. 게임 중에만 표시되고 시작 화면에서는 숨는다 |
| `BGM` | 배경음악 음량 (Mute · 1 · 2 · 3), localStorage에 저장 |

상태 배지는 색과 문구를 **항상 같이** 바꿉니다. 색만으로 알리면 색각 이상이 있는 사람에게는 구분이 사라지므로, 문구만 읽어도 상태를 알 수 있게 했습니다.

| 상태 | 문구 | 색 | 비고 |
|---|---|---|---|
| `title` | 대기 중 | 회녹색 `#9fb8ab` | |
| `countdown` | 준비! | 노랑 `#ffd166` | 점이 깜빡인다 |
| `playing` | 진행 중 | 네온 그린 `#39ff88` | 점이 깜빡인다 |
| `paused` | 일시정지 | 하늘색 `#6bc9ff` | |
| `win` | 승리! | 라임 `#b9ff5a` | |
| `lose` | 게임 오버 | 빨강 `#ff6b81` | |

멈춘 상태와 흐르는 상태를 한눈에 가르기 위해 `countdown` · `playing`에서만 점이 맥박처럼 뜁니다. `prefers-reduced-motion`을 켠 환경에서는 이 애니메이션이 꺼집니다.

### 규칙

- 그리드 **32 × 18** (576칸), 뱀은 중앙에서 길이 **5**로 시작
- 쥐는 뱀의 머리·몸통이 없는 칸 중에서만 무작위로 생성되며, 먹은 **바로 그 틱에** 다음 쥐가 나타난다 (튀어나오는 파문 연출로 위치를 바로 알 수 있음)
- 쥐를 먹을 때마다 몸통이 한 칸 길어지고 **Mice 1**이 적립된다
- **승리** — 길이 **400** 달성 시 `You Win!`
- **패배** — 그리드를 벗어나거나 자기 몸통 칸으로 진입하면 `Better Luck Next Time`
- 이기든 지든 그 판에서 먹은 쥐 수만큼 Mice가 지급된다

### 속도 곡선

**2.4칸/초**에서 시작해, 쥐 하나를 먹을 때마다 **정확히 +0.0395칸/초**씩 균일하게 빨라집니다. 승리 길이인 400칸에서 최고 속도 **18칸/초**에 도달합니다.

```
speed(len)    = 2.4 + (18 - 2.4) × (len - 5) / 395     // 칸/초
interval(len) = 1000 / speed(len)                       // ms
```

| 길이 | 5 | 105 | 205 | 305 | 400 |
|---|---|---|---|---|---|
| 속도 | 2.40 | 6.35 | 10.30 | 14.25 | 18.00칸/초 |
| 간격 | 417ms | 157ms | 97ms | 70ms | 56ms |

배경음악 템포가 이 속도를 그대로 따라갑니다 — **102 BPM → 210 BPM**.

### 뱀 그리기

몸통은 타일 단위 사각형이 아니라 **머리부터 꼬리까지 하나로 이어진 관**으로 그립니다. 세그먼트 중심을 지나는 꺾은선을 둥근 이음새로 스트로크해 코너가 부드럽게 휘고, 꼬리 쪽 11칸은 굵기가 점점 가늘어집니다. 머리는 종에 따라 창끝 / 뭉툭 / 길쭉 세 가지 모양이 있고, 동공은 원형 또는 세로 슬릿입니다.

띠 무늬 스킨은 **바탕 관을 먼저 깔고 그 위에 `butt` 캡으로 띠를 얹습니다.** 둥근 캡으로 칠하면 띠 끝이 둥글어져 타원처럼 보이는데, 이렇게 하면 각진 사각 띠가 되면서 코너에서도 관이 끊기지 않습니다.

몸 아래에는 옅은 그림자를 깔아 흙바닥에서 뱀이 떠 보이게 했습니다.

### 스킨 상점

시작 화면의 **상점** 버튼에서 Mice로 뱀 스킨을 살 수 있습니다. 카드 크기를 캔버스 높이에 비례시켜(`container-type: size` + `cqh`), 창 크기와 무관하게 **5종이 스크롤 없이 한 줄에** 들어갑니다.

| 스킨 | 학명 | 가격 | 생김새 |
|---|---|---:|---|
| 캘리포니아 킹스네이크 | *Lampropeltis californiae* | 기본 제공 | 검은 몸에 크림색 띠 |
| 밀크스네이크 | *Lampropeltis triangulum* | 🐭 500 | 빨강·검정·흰색 띠가 균일하게 반복 |
| 볼파이톤 | *Python regius* | 🐭 700 | 굵은 몸통, 황금 얼룩이 좌우 교대, 뭉툭한 머리 |
| 그린 아나콘다 | *Eunectes murinus* | 🐭 700 | 가장 굵은 몸통, 검은 타원이 어긋나게 배치 |
| 킹코브라 | *Ophiophagus hannah* | 🐭 1000 | 활짝 펼친 후드와 갈매기 무늬, 가늘고 긴 머리 |

색만 바꾼 것이 아니라 **몸통 굵기(`girth`), 머리 모양(창끝/뭉툭/길쭉), 동공(원형/세로), 후드 유무**가 종마다 다릅니다. 아나콘다가 가장 굵고 킹코브라가 가장 가늘며, 킹코브라만 머리 뒤로 후드가 펼쳐집니다.

무늬는 세그먼트마다 붙는 **고유 번호(seq)** 를 기준으로 찍힙니다. 배열 인덱스를 쓰면 뱀이 자랄 때마다 무늬가 몸을 따라 흘러 이질감이 생기는데, seq를 쓰면 한번 찍힌 띠가 그 몸 조각에 고정됩니다.

가격은 인기도에 따라 500 / 700 / 1000 세 단계입니다. 보유 스킨·장착 스킨·Mice는 localStorage에 저장됩니다.

### 배경

마른 **흙밭**입니다. 흙이 뭉친 자국, 갈라진 골, 모래 알갱이와 잔돌을 시작 시 한 번 오프스크린 캔버스에 그려두고 매 프레임 `drawImage` 한 번으로 재사용합니다.

채도를 낮추고 충분히 어둡게 깔아, 검정(킹스네이크)·빨강(밀크)·황금(볼파이톤)·올리브(아나콘다)·황갈(코브라) 다섯 스킨과 밝은 회색 쥐가 모두 바닥에 묻히지 않습니다.

### 사운드

음원 파일 없이 **Web Audio API로 실시간 합성**하는 8비트 칩튠입니다. 펄스파(리드/하모니) + 삼각파(베이스) + 노이즈(퍼커션) 구성으로, 수록곡(타이틀 · 게임플레이 · 승리 · 패배 징글)은 모두 오리지널 창작곡입니다.

배경음악 음량은 **Mute · 1 · 2 · 3** 네 단계이고 설정은 저장됩니다. 게임플레이 곡은 **뱀 속도에 맞춰 템포가 올라갑니다** (102 → 210 BPM). 새 쥐가 나타날 때는 작게 "찍찍" 소리가 납니다. 일시정지하면 재생 위치를 유지한 채 멈췄다가 재개됩니다. 브라우저 자동재생 정책상 첫 클릭이나 키 입력 전까지는 소리가 나지 않습니다.


### 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 상단 바 · 상태 배지 · 캔버스 · 버튼 오버레이 · 상점 패널 · 터치 조작부 마크업 |
| `styles.css` | 레트로 네온 테마, 16:9 반응형 레이아웃, 상점 카드, 상태 배지 색, 모바일 레이아웃 |
| `script.js` | 1부 칩튠 사운드 엔진(`Chip`) + 2부 게임 본체(`SNAKE`) |

`script.js`는 `Chip`이 먼저 정의되어야 게임 본체가 이를 참조할 수 있으므로 **오디오 → 게임** 순서를 지킵니다.

### v0.5.1 — 파일 3개로 정리, 모바일 조작부, 상태 배지

- **파일 구성을 3개로** — `style.css` → `styles.css`, `audio.js` + `game.js` → `script.js` 한 파일로 병합(1부 오디오 / 2부 게임). 렌더링·오디오 로직은 그대로 옮겼고 동작 변경 없음
- **상태 배지** 추가 — 6개 상태(`title` `countdown` `playing` `paused` `win` `lose`)를 상단 바에서 **점 색깔과 문구로 함께** 표시. 색과 문구를 `renderBadge()` 한 곳에서 같이 갈아끼워 둘이 어긋날 여지를 없앰. `countdown` · `playing`에서만 점이 맥박처럼 뛰고, `prefers-reduced-motion`에서는 꺼짐
- **터치 조작부** 추가 — 캔버스 아래 십자 방향 버튼과 상태별로 역할이 바뀌는 가운데 버튼. 한 변 64px 이상, `pointerdown`으로 수신. 방향 입력이 통하지 않는 상태에서는 방향 버튼이 흐려지고 비활성
- **캔버스 스와이프** 추가 — 24px 이상 밀면 그 방향으로. 대각선은 더 많이 움직인 축만 읽음
- 방향 입력을 **`turn()` 한 함수로 통합** — 키보드와 터치가 역방향 차단·입력 큐 2개 제한을 같은 규칙으로 탐
- **모바일 레이아웃** — 상단 바 줄바꿈(좁은 화면 2×2), 상태 배지 한 줄 차지, 오버레이 버튼과 `BGM` 버튼 44px 이상, 상점을 전체화면 2~3열로, 가로로 눕힌 휴대폰에서는 조작부를 캔버스 오른쪽으로
- 조작부 버튼 높이를 `clamp(54px, 8.4vh, 78px)`로 — 정사각형으로 두면 3행이 260px을 넘어 세로가 짧은 휴대폰에서 잘림

### v0.5 — 흙밭 바닥, 사각 띠, BGM 4단계

- **상점** 카드 크기를 캔버스 높이에 비례시켜(`container-type: size` + `cqh`) 창 크기와 무관하게 **5종이 스크롤 없이 한 줄에** 들어가도록 변경. 생김새 설명 캡션과 학명을 카드에서 제거하고 미리보기 축소
- **띠 무늬**가 캡슐처럼 보이던 문제 수정 — 바탕 관을 먼저 깔고 그 위에 `butt` 캡으로 띠를 얹어 각진 사각 띠로
- **킹코브라 후드** 축소 (폭 3.6bw → 2.2bw), 원반형 → 목으로 이어지는 방추형

- 스킨을 **지정 5종으로 교체** — 캘리포니아 킹스네이크(기본) / 밀크스네이크 / 볼파이톤 / 그린 아나콘다 / 킹코브라. 색만이 아니라 **몸통 굵기, 머리 모양, 동공, 후드 유무**를 종마다 다르게
- 무늬 기준을 배열 인덱스에서 **세그먼트 고유번호(seq)** 로 변경 — 뱀이 길어져도 무늬가 몸을 따라 흐르지 않음
- 새 쥐가 나타날 때 **"찍찍" 효과음** 추가
- 시작 속도 1.4 → **2.4칸/초** (최고 속도는 18칸/초 유지), BGM 템포 연동 폭을 **102 ~ 210 BPM**으로 확대
- 시작 화면에서 `승리까지` 숨김
- 스킨 비교용 `SNAKE.sheet()`, `Chip.tempo()` 추가

### v0.3 — 이어진 뱀과 스킨 상점

- 뱀을 타일 사각형 나열이 아니라 **머리부터 꼬리까지 이어진 관**으로 렌더링 (Green Tree Python 모티브). 코너가 부드럽게 휘고 꼬리가 가늘어짐
- 검은 배경을 **숲 바닥**(이끼·흙 텍스처)으로 교체
- **스킨 상점**과 재화 추가 — 쥐 1마리당 1, 게임 종료 시 그 판에서 먹은 만큼 지급
- 승리 길이 355 → **400**, 종료 화면 표기를 `LENGTH` → `SCORE`로 변경하고 획득 재화 표시
- 먹이 **등장 연출**(스케일 + 파문) 추가 — 측정 결과 로직 지연은 0프레임이었고, 작은 쥐가 눈에 띄지 않는 것이 원인이었음
