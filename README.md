# Game_Practice

Practicing making a web game with AI

## 🐍 SNAKE

바닐라 HTML / CSS / JavaScript로 만든 스네이크 게임. 외부 라이브러리도, 이미지도, 음원 파일도 없습니다. 뱀·쥐·바닥·로고·음악까지 전부 코드로 그리고 만듭니다.

### 실행

```bash
python -m http.server 8123
```

브라우저에서 `http://localhost:8123` 접속.

### 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 뱀 이동 (한글 자판 상태에서도 `ㅈㅁㄴㅇ`로 동작) |
| `ESC` | 일시정지 / 재개 (상점이 열려 있으면 닫기) |
| `M` | 배경음악 켜기 / 끄기 |
| `Space` / `Enter` | 화면 넘기기 (시작 · 메인으로) |

진행 방향의 정반대 입력은 즉사를 막기 위해 무시합니다. 한 틱에 최대 2개까지 입력을 큐에 담아 빠른 연속 조작을 받아냅니다. 조작법은 시작 화면에도 표시됩니다.

### 화면 구성

게임 화면 위에는 아무 UI도 얹지 않았습니다. 캔버스 **바깥 상단 바**에 다음이 놓입니다.

| 위치 | 내용 |
|---|---|
| `HI-SCORE` | 역대 최고 점수 |
| `🪙 은` | 보유 재화 |
| `승리까지` | 승리(400)까지 남은 칸 수. 시작 시 **395** |
| `BGM` | 배경음악 토글 |

### 규칙

- 그리드 **32 × 18** (576칸), 뱀은 중앙에서 길이 **5**로 시작
- 쥐는 뱀의 머리·몸통이 없는 칸 중에서만 무작위로 생성되며, 먹은 **바로 그 틱에** 다음 쥐가 나타난다 (튀어나오는 파문 연출로 위치를 바로 알 수 있음)
- 쥐를 먹을 때마다 몸통이 한 칸 길어지고 **은 1개**가 적립된다
- **승리** — 길이 **400** 달성 시 `You Win!`
- **패배** — 그리드를 벗어나거나 자기 몸통 칸으로 진입하면 `Better Luck Next Time`
- 이기든 지든 그 판에서 먹은 쥐 수만큼 은이 지급된다

### 속도 곡선

**1.4칸/초**에서 시작해, 쥐 하나를 먹을 때마다 **정확히 +0.042칸/초**씩 균일하게 빨라집니다. 승리 길이인 400칸에서 최고 속도 **18칸/초**에 도달합니다.

```
speed(len)    = 1.4 + (18 - 1.4) × (len - 5) / 395     // 칸/초
interval(len) = 1000 / speed(len)                       // ms
```

| 길이 | 5 | 105 | 205 | 305 | 400 |
|---|---|---|---|---|---|
| 속도 | 1.40 | 5.60 | 9.80 | 14.00 | 18.00칸/초 |
| 간격 | 714ms | 179ms | 102ms | 71ms | 56ms |

### 뱀 그리기

몸통은 타일 단위 사각형이 아니라 **머리부터 꼬리까지 하나로 이어진 관**으로 그립니다. 세그먼트 중심을 지나는 꺾은선을 둥근 이음새로 스트로크해 코너가 부드럽게 휘고, 꼬리 쪽 11칸은 굵기가 점점 가늘어집니다. 머리는 창끝 모양에 세로 동공을 가진 눈과 이따금 날름거리는 갈라진 혀가 달려 있습니다.

### 스킨 상점

시작 화면의 **상점** 버튼에서 은으로 뱀 스킨을 살 수 있습니다. 모두 실제 뱀을 모티브로 했습니다.

| 스킨 | 학명 | 가격 | 무늬 |
|---|---|---:|---|
| 녹색나무비단뱀 | *Morelia viridis* | 기본 제공 | 등줄을 따라 끊긴 흰 마름모 |
| 가터뱀 | *Thamnophis sirtalis* | 🪙 500 | 머리부터 꼬리까지 흐르는 노란 세로줄 |
| 옥수수뱀 | *Pantherophis guttatus* | 🪙 700 | 주황 바탕에 검은 테를 두른 붉은 안장무늬 |
| 밀크스네이크 | *Lampropeltis triangulum* | 🪙 700 | 빨강·검정·흰색 반복 밴드 |
| 알비노 버미즈 파이톤 | *Python bivittatus* | 🪙 1000 | 흰 바탕에 번지는 노란 얼룩 |
| 서부 다이아몬드방울뱀 | *Crotalus atrox* | 🪙 1000 | 사막 모래빛 몸을 덮은 다이아몬드 무늬 |

가격은 인기도에 따라 500 / 700 / 1000 세 단계입니다. 보유 스킨·장착 스킨·은은 localStorage에 저장됩니다.

### 배경

숲 바닥을 모티브로 한 이끼·흙 텍스처를 시작 시 한 번 오프스크린 캔버스에 그려 재사용합니다. 먹이인 쥐(밝은 회색·분홍)와 확실히 구분되는 어두운 이끼색을 골랐습니다.

### 사운드

음원 파일 없이 **Web Audio API로 실시간 합성**하는 8비트 칩튠입니다. 펄스파(리드/하모니) + 삼각파(베이스) + 노이즈(퍼커션) 구성으로, 수록곡(타이틀 · 게임플레이 · 승리 · 패배 징글)은 모두 오리지널 창작곡입니다.

게임플레이 곡은 **뱀 속도에 맞춰 템포가 올라갑니다** (96 → 186 BPM). 일시정지하면 재생 위치를 유지한 채 멈췄다가 재개됩니다. 브라우저 자동재생 정책상 첫 클릭이나 키 입력 전까지는 소리가 나지 않습니다.

### 디버그

게임 진행 중에만 동작하는 단축키:

| 키 | 동작 |
|---|---|
| `` ` `` | 길이 +50 (은은 실제로 먹은 쥐만 계산되므로 늘지 않는다) |
| `Shift` + `W` | 즉시 승리 화면 |
| `Shift` + `L` | 즉시 패배 화면 |

브라우저 콘솔:

```js
SNAKE.state()        // 상태 · 길이 · 속도 · 남은 칸 · 은 · 스킨 · 머리/먹이 좌표
SNAKE.curve(50)      // 속도 곡선 전체 출력
SNAKE.grantSilver(n) // 은 지급 (상점 확인용)
```
